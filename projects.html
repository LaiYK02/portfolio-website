Maze Ball Physics Game

2026

Maze Ball Physics Game is a 3D physics-based maze game developed using Processing (Java Mode). Players control a rolling ball by tilting the maze board, navigating around obstacles, avoiding holes, and reaching the goal area in the shortest time possible. The project implements realistic physics concepts such as gravity, friction, restitution, collision detection, and velocity-based movement. Additional features include a tutorial system, persistent leaderboard, win screen, and adjustable physics settings for gameplay experimentation.

  • 3D Physics-Based Gameplay
  • Gravity & Friction Simulation
  • Collision Detection System
  • Persistent High Score Leaderboard

Computer Components Trading System

2025-2026

Computer Components Trading System is a database-driven business management application developed using C++ and MySQL. The system was designed to help computer hardware businesses manage inventory, customer orders, and sales records efficiently. It provides separate admin and customer modules, allowing administrators to manage products, users, and sales reports, while customers can browse components, place orders, and view their purchase history. The project strengthened my skills in database design, SQL integration, and software development using object-oriented programming principles.

Cathedral Manor

2025-2026

Cathedral Manor is a mobile endless runner game developed using Unity for Android devices. Players take on the role of a Ghostbuster trapped inside a haunted manor filled with ghosts and dangerous obstacles. The objective is to survive as long as possible while collecting energy batteries and avoiding hazards. The game features an energy-based combat system where players can charge their energy bar and unleash a powerful laser attack to eliminate ghosts. This project helped me strengthen my skills in mobile game development, gameplay programming, user input handling, and Unity-based game design.

  • Endless Runner Gameplay
  • Swipe Movement Controls
  • Energy Collection System
  • Laser Shooting Mechanic

Jumping Meow

2025-2026

Jumping Meow is a 2D endless vertical platformer developed using C++, OpenGL, and FreeGLUT. Players control a jumping cat that continuously climbs upward through multiple themed biomes while avoiding enemies, collecting power-ups, and achieving the highest score possible. The game features procedural platform generation, custom gravity and jump physics, particle effects, dynamic audio systems, and a unique "Oiiai Mode" transformation power-up. Through this project, I gained valuable experience in graphics programming, game physics, procedural content generation, and gameplay system design using modern C++.

  • Endless Vertical Platformer Gameplay
  • Procedural Platform Generation
  • Custom Physics & Jump Mechanics
  • Oiiai Mode Transformation System
