\# Personal Portfolio Website



A modern personal portfolio website built using HTML, CSS, and JavaScript to showcase my projects, technical skills, academic background, and creative works as a game programmer and interactive media student.



\## Features



\- Responsive modern UI design

\- Personal introduction section

\- Project showcase section

\- Skills and tools section

\- Contact information

\- Interactive portfolio layout

\- Clean and minimal interface design



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript

\- Visual Studio Code

\- Git \& GitHub



\## Purpose



This portfolio website was developed as part of my university coursework and personal learning journey in web development and Human-Computer Interaction (HCI). The website is designed to present my academic projects, game development works, multimedia skills, and technical experiences in a professional and interactive format.
