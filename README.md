\# 🎨 Personal Portfolio Website



A responsive personal portfolio website developed using HTML, CSS, and JavaScript to showcase my academic journey, technical projects, game development experience, and personal qualities as a Game Programmer and Interactive Media student.



\## 🌐 Live Website



Visit the portfolio here:



https://laiyk02.github.io/portfolio-website/



\## 📖 About



This website serves as my personal online portfolio, highlighting my educational background, software development projects, game development experience, technical skills, and personal achievements.



The portfolio was designed with a modern and responsive user interface to provide an engaging experience across desktop, tablet, and mobile devices.

\## 🎮 Featured Projects



\### Maze Ball Physics Game



A 3D physics-based maze game developed using Processing (Java Mode), featuring realistic ball movement, collision detection, gravity simulation, and a persistent leaderboard.



\### Computer Components Trading System



A database-driven business management system built with C++ and MySQL for inventory management, customer orders, and sales tracking.



\### Cathedral Manor



A Unity-based endless runner mobile game featuring energy collection mechanics, laser combat, and obstacle avoidance gameplay.



\### To The Top of The Tower



A turn-based deck-building strategy game developed in C++, combining card combat mechanics with procedural encounters and leaderboard functionality.



\### Jumping Meow



A 2D endless vertical platformer developed using C++, OpenGL, and FreeGLUT, featuring procedural platform generation and increasing gameplay difficulty.



\### Ana Muslim Maze Adventure



An educational maze game inspired by the Ana Muslim series, designed to combine entertainment with problem-solving gameplay.

\## 🚀 Deployment



This portfolio website is deployed using GitHub Pages.



To run locally:



1\. Clone the repository



```bash

git clone https://github.com/LaiYK02/portfolio-website.git

```



2\. Open the project folder



3\. Launch `index.html` using Live Server or any web browser
